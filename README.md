# Sistema de Agendamento de Consultas Médicas

## Descrição do Projeto

Este repositório contém a documentação do projeto de desenvolvimento de um aplicativo móvel para agendamento de consultas médicas. O projeto encontra-se em fase intermediária de desenvolvimento e aborda aspectos relacionados à gestão do projeto, planejamento das entregas, análise de riscos e documentação técnica.

## Objetivo do Exercício

Demonstrar a organização de um projeto de desenvolvimento de software utilizando um repositório Git, documentação em Markdown e histórico de commits que representem a evolução das atividades.

## Organização do Repositório

```
docs/
    Documentação do projeto.

diagrams/
    Diagramas e representações da arquitetura.

assets/
    Imagens e arquivos auxiliares.
```

Cada documento aborda um aspecto específico da gestão do projeto, permitindo acompanhar sua evolução de forma organizada.
