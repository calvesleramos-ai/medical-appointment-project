# Contexto do Projeto

## Visão Geral

O projeto consiste no desenvolvimento de um aplicativo móvel para agendamento de consultas médicas.

As principais funcionalidades previstas são:

- Cadastro de usuários;
- Cadastro de médicos;
- Gestão da agenda médica;
- Agendamento de consultas;
- Cancelamento de consultas;
- Envio de notificações;
- Integração com um sistema externo de prontuário eletrônico.

## Situação Atual

O projeto encontra-se em fase intermediária de desenvolvimento.

Parte das funcionalidades já foi implementada, porém novos desafios surgiram durante a execução do projeto.

## Problemas Identificados

- Instabilidade da API do sistema de prontuário.
- Alterações recentes nos requisitos de negócio.
- Sobrecarga da equipe de desenvolvimento.
- Dependência crítica da integração externa.
