# Plano de Sprint

## Objetivo

Reorganizar as atividades para estabilizar a integração com o sistema externo sem comprometer a entrega do projeto.

## Equipe

- Desenvolvedor 1: Integração com API
- Desenvolvedor 2: Fluxo de agendamento
- Desenvolvedor 3: Correções e refatoração
- Desenvolvedor 4: Notificações e suporte
- Tester: Testes contínuos e regressão

## Sprint 1

- Estabilizar integração
- Criar Mock API
- Corrigir bugs críticos

## Sprint 2

- Implementar novas regras de negócio
- Executar testes integrados
- Preparar homologação

## Critérios de sucesso

- API estabilizada
- Testes aprovados
- Backlog atualizado
